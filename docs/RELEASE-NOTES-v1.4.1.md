## CloudUnhideWatcher v1.4.1

Help viewer quality release — diagrams, tables, sidebar, and in-page links.

### Fixed

- **Help diagrams** — Mermaid flowcharts in Process Flows, Architecture, Getting Started, and related pages render as resizable SVG charts (offline).
- **Help tables** — Settings Reference and other pipe tables display as readable HTML tables.
- **Help sidebar** — Grouped browse menu: **Start here**, **Guides**, **Reference** (no raw markdown snippets).
- **In-page links** — Clicking documentation links inside Help loads the converted page (not raw `.md` source).

### Install

Download `CloudUnhideWatcher-1.4.1-macos.dmg`, drag to Applications, and relaunch. Bundle ID remains `com.cloudunhidewatcher` (same as v1.4.0).
